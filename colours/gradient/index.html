“Is life a random gradient?” rolls the whole composition; RANDOMISE COLOURS rolls the colours alone.

COLOURS — click a box to pick, paste any text carrying hex codes, or drop a swatch file on the page; a single colour derives its own light and dark. Drag the handles under the boxes to place each colour; double-click the ramp to reset; two handles on one colour hold a flat.

TYPE — LINEAR takes an angle. RADIAL: click the canvas to place the centre, set the radius on the slider. MULTI-POINT scatters blurred masses; RANDOMISE POINTS reshuffles them. SEAMLESS closes a linear loop so two prints butt without a break.

BLEND — the route between colours: VIVID keeps saturation, EVEN is smoothest, LEGACY is the old sRGB way; the easing curve sits beside it.

PATTERN flattens the gradient into vector tiles. GRAIN lays film-like texture counted along the height — AMOUNT, COUNT, BITE.

SIZE is a ratio and an output height, width follows; WINDOW tracks this window. SVG and PNG export exactly what is on screen.
